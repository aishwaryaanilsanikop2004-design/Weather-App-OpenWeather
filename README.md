# Weather App with Live OpenWeather API

## Project Description
A Python application that fetches real-time weather information using the OpenWeather API.

## Features
- Search weather by city
- Temperature
- Feels-like temperature
- Humidity
- Weather condition
- Wind speed
- JSON response handling
- Error handling

## Technologies Used
- Python
- Requests
- OpenWeather API
- JSON

## How to Run
1. Install Python.
2. Install requests:
   pip install requests
3. Add your OpenWeather API key.
4. Run:
   python weather_app.py
5. Enter a city name.

## Output
The application displays real-time weather information for the selected city.
